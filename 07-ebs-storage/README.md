# 07 - Amazon EBS Storage

**Status:** In Progress

## Project Goal

Create an EC2 instance and attach an Amazon Elastic Block Store (EBS) volume to provide additional persistent block storage.

## Planned AWS Services & Skills

- Amazon EC2
- Amazon EBS
- EBS volumes
- Storage attachment
- Availability Zones
- Security groups
- Linux storage concepts

## What This Project Will Demonstrate

- Creating cloud block storage
- Attaching storage to an EC2 instance
- Understanding persistent storage
- Managing compute and storage as separate AWS resources
- Validating that an attached volume is available to the instance
