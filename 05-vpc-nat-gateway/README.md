# 05 - VPC with Public/Private Subnets and NAT Gateway

**Status:** In Progress

## Project Goal

Build a more complete AWS network with public and private subnets, EC2 connectivity, an internet gateway, route tables, and a NAT gateway.

## Planned Components

- Custom VPC
- Public subnet
- Private subnet
- Internet gateway
- Public and private route tables
- NAT gateway
- EC2 instances
- Security group
- SSH / PuTTY connectivity
- Internet connectivity testing

## What This Project Will Demonstrate

- Public vs. private subnet design
- Routing decisions in AWS
- Outbound internet access from private resources
- EC2 connectivity and troubleshooting
- Security-group and route-table relationships
