# 06 - Amazon RDS MariaDB Architecture

**Status:** In Progress

## Project Goal

Build an AWS environment that combines networking, compute, and managed database services.

## Planned Architecture

- Custom VPC
- Public and private subnets
- Amazon EC2 instances
- Amazon RDS
- MariaDB database instances
- Security groups
- EC2-to-database connectivity
- PuTTY / SSH administration

## Planned Tasks

- Create the VPC.
- Deploy EC2 instances.
- Create MariaDB database instances with Amazon RDS.
- Configure the required networking and access.
- Connect EC2 instances to the databases.
- Validate database connectivity.

## Why This Project Matters

This is a larger project because it combines skills from earlier labs instead of focusing on a single AWS service. It demonstrates how compute, networking, security, and databases work together in a cloud architecture.

## Evidence

Architecture screenshots, resource status, and successful database connectivity will be documented after the lab is completed.
